၁။ 🔐 စတင်ခြင်း (Login)

  • အကောင့်အသစ်ဖန်တီး tab → Email + Password (၆ လုံးအနည်းဆုံး) + Confirm → ✨ အကောင့်ဖန်တီးမည်
  • ရှိပြီးသားအကောင့်ဆို ဝင်မည် tab နဲ့ ဝင်ပါ
  • Password မေ့နေလား? — Email အရင်ရိုက်ထည့်ပြီးမှ နှိပ်ပါ။ Reset link ကို Email inbox ထဲ ပို့ပေးမယ် (Spam folder လည်း စစ်ပါ)
  • တစ်ခါဝင်ပြီးရင် ဖုန်းပိတ်ဖွင့်လည်း ပြန်ဝင်စရာမလို — အလိုအလျောက် မှတ်ထားမယ်
  • ထွက်ချင်ရင် ညာဘက်အပေါ် 🚪 နှိပ်
  • 💡 ဖုန်း၊ Tablet၊ ကွန်ပျူတာ — ဘယ်စက်မှာမဆို same email နဲ့ဝင်ရင် data အကုန်တူတူ မြင်ရမယ်

၂။ 🧭 App ဖွဲ့စည်းပုံ

🎯 2Dနေ့စဉ် ဒိုင်လုပ်ငန်း — Draw ဖွင့်၊ ထိုးငွေထည့်၊ ကာ၊ ပေါက်ရှင်း၊ စာရင်းရှင်း
📊 Weekတစ်ပတ်စာ အရှုံးအမြတ် စာရင်းချုပ် (၅ ရက် × ၂ ပွဲ = ၁၀ ကြိမ်)
📅 Calendarလ-အလိုက် ရက်တိုင်း P/L အရောင်ပြ ပြက္ခဒိန်
📈 Monthlyလချုပ် + ယခင်လနှိုင်းယှဉ် + တစ်နှစ်စာ Trend
⚙️ Settingထိုးသား၊ ကော်၊ Limit၊ ပိတ်ဂဏန်း၊ Data ဖျက်

💡 2D module နဲ့ Week tracker က ချိတ်ဆက်ထား — Draw ရှင်းရင် Week ထဲ auto ဝင်မယ်။ ဒါပေမယ့် Week ကို သီးသန့်လည်း (2D မသုံးပဲ) ကိုယ်တိုင်ရိုက်ထည့် သုံးလို့ရတယ်။

၃။ ⚙️ Setting — အရင်ဆုံး ပြင်ဆင်ပါ

က) ထိုးသားများ ထည့်ခြင်း

  • နာမည် + ကော် % ရိုက် → + ထည့် (ဥပမာ: ကိုကို + 15 → ကိုကို /15%)
  • ကော် % ဆိုတာ — ထိုးသားက သူ့ရောင်းရငွေပေါ် ရမယ့် ကော်မရှင်
  • ✏️ နှိပ်ရင် နာမည်/ကော် ပြင်လို့ရ၊ 🗑️ နှိပ်ရင် ဖျက်

ခ) 2D Settings

Limitနံပါတ်တစ်လုံးကို လက်ခံမယ့် အများဆုံးပမာဏ (default 50,000)
ကော် %စာရင်းကော် — ရောင်းရငွေအားလုံးပေါ် နှုတ်မယ့် % (default 18)
လျော် ×ပေါက်ရင် လျော်ရမယ့်အဆ (default 80)

ဂ) ပိတ်ဂဏန်းများ — လုံးဝ လက်မခံချင်တဲ့ နံပါတ်တွေ။ ထိုးလာရင် အလိုအလျောက် ပယ်ပြီး သတိပေးမယ်။

ဃ) နံပါတ်အလိုက် Limit — သီးခြားနံပါတ်တွေအတွက် default limit ထက် ကွဲပြားတဲ့ limit (ဥပမာ 36 ကို 20,000 ပဲ လက်ခံမယ်)

⚠️ Danger Zone — "2D Draw Data အားလုံးဖျက်မည်" က Draw အကုန်ဖျက်တယ်။ Week tracker data တော့ မပျက်ဘူး။ ပြန်ယူလို့ မရဘူး!

၄။ 🎯 Draw ဖွင့်ခြင်း

  1. 🎯 2D tab → Draw များ ရွေးထား
  2. ရက်စွဲရွေး → မနက် / ည ရွေး → + ဖွင့်
  3. Draw card ကို နှိပ်ရင် အထဲဝင်မယ် — tab ၅ ခု: ထည့် / စာရင်း / ဂဏန်း / ကာ / ပေါက်
  4. အပေါ်မှာ ရောင်းရ / ကာပြီး / Net အမြဲမြင်ရမယ်
  5. Draw ဖျက်ချင်ရင် စာရင်းထဲက 🗑️ (ထိုးငွေအကုန် ပါပျက်မယ်)

💡 ရက် + ပွဲချိန်တူ Draw က တစ်ခုပဲ ရှိလို့ရတယ်။ ရှိပြီးသားကို ထပ်ဖွင့်ရင် အဟောင်းထဲ ဝင်သွားမယ်။

၅။ ✍️ ထိုးငွေ ထည့်နည်း (ထည့် tab)

  1. ထိုးသား dropdown က ရွေး
  2. စာရိုက် (သို့) Viber message ကို 📋 ခလုတ်နဲ့ paste
  3. ထည့်မည် နှိပ် — အကွက်တစ်ခုချင်း လက်ခံ/ကာ ပြမယ်

  • 🟥 အနီ — limit ပြည့်ပြီ (နောက်ထပ်လာရင် ကာထဲ auto ဝင်မယ်)

  • ထိပ်ဆုံးကွက်တွေ = အန္တရာယ်အကြီးဆုံး — ပေါက်ရင် အများဆုံးလျော်ရမယ့်ကွက်တွေ
  • ထိုးငွေ သိသိသာသာ တက်လာတဲ့ကွက်ကို ကြိုဝယ် (ကြိုကာ) — limit မပြည့်ခင် ကိုယ့်ဘက်က တခြားဒိုင်ကို ကြိုတင်လွှဲ
  • ထိုးသားနာမည်ကြည့်ပြီး ဘယ်သူက ဘယ်ကွက်ကို စုထိုးနေလဲ ချက်ချင်းသိ
  • ထည့်မည် နှိပ်တိုင်း / Share ကနေထည့်တိုင်း ချက်ချင်း auto update ဖြစ်တယ်

၁၆။ 🧮 ဖော်မြူလာများ (ဥပမာနဲ့)

ရောင်း P/L

ရောင်း P/L = ထိုးငွေ − (ထိုးငွေ × ကော်%) − (ပေါက် × 80)

ဥပမာ: 1,000,000 ရောင်း, 5,000 ပေါက်, ကော် 18%
= 1,000,000 − 180,000 − 400,000 = +420,000

ကာ P/L (ဒိုင်ကော် 16% ဆိုရင်)

ကာ P/L = (ကာပေါက် × 80) − ကာတင် × (1 − 16%)

ဥပမာ: 500,000 ကာ, 2,000 ပေါက်
= 160,000 − 420,000 = −260,000

အသားတင်

အသားတင် = ရောင်း P/L + ကာ P/L − စက်ရိုက်ခ

Partner ဝေစု

ဝေစု = အသားတင် × Partner %

ဥပမာ: −1,550,000 × 40% = −620,000

ထိုးသား စာရင်းရှင်း

စာရင်း = ရောင်းရ − (ပေါက် × 80) − (ရောင်းရ × ထိုးသားကော်%)

ဥပမာ: KoKo — 200,000 ရောင်း, မပေါက်, ကော် 10%
= 200,000 − 0 − 20,000 = +180,000 (KoKo က ပေးရမယ်)
